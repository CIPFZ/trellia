# ADR-007：不新增字母键，M3 翻转键为 F2

- 编号：ADR-007
- 标题：`Key` 枚举不新增字母键 F；修正 SPEC.md 13 M3 措辞
- 日期：2026-10-13
- 状态：已接受（负责人裁决）

## 背景

SPEC.md 4.9 规定 `Key` 枚举“v1 仅此。新增需引用用例”，其中没有字母键；13 M3 的 `sprites`
验收写作“F 键翻转”。两种解读导致公共 API 不同（是否新增 `Key::F`），按 AGENT.md 3.3 提交负责人裁决。

## 决策

不新增 `Key::F`。SPEC.md 13 M3 的措辞修正为“F2 键翻转”，`examples/sprites` 中
`FLIP_KEY = Key::F2` 保持不变。

## 理由

1. 4.9 要求新增按键必须引用用例，而第 2 章没有任何用例需要字母键；PvZ 的键盘需求只有
   Esc、空格、数字键与功能键。
2. M3 的“F 键翻转”是编写验收条件时的笔误，属于 SPEC 内部矛盾，应修正验收文字而不是扩大公共 API。
3. 示例是引擎的消费者而非需求来源；为示例的便利修改引擎 API 正是 AGENT.md 4.3 要防止的范围蔓延。

## 后果

- `Key` 枚举保持 SPEC.md 4.9 原样。
- SPEC.md 13 M3 一处措辞修改（经负责人明确授权；AGENT.md 规定 SPEC.md 对实现者只读）。

## 替代方案

- 新增 `Key::F`（以 M3 验收为依据）：无对应用例，扩大公共 API，否决。
